HOW TO HOST (free, needs HTTPS):
1. Go to https://app.netlify.com/drop and drag this whole folder in. (Or use GitHub Pages / Cloudflare Pages.)
2. Open the link on your phone in Chrome (Android) or Safari (iPhone).
3. Android: menu > "Install app". iPhone: Share > "Add to Home Screen".
4. Open the app > Summary tab > tap "Enable month-end notifications".
